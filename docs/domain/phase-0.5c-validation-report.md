# PHASE 0.5C — RAPPORT HISTORIQUE, REMPLACÉ PAR LA PHASE 0.5D

> Ce fichier est conservé pour la traçabilité. Le rapport initial de Phase 0.5C concluait prématurément à un `GO` alors que plusieurs anciennes formulations subsistaient dans le document principal.
>
> **Le statut de référence est désormais celui de [phase-0.5d-consistency-report.md](phase-0.5d-consistency-report.md).**

## 1. Pourquoi la Phase 0.5C a été rouverte

Les contrôles ultérieurs ont identifié notamment :

- une date incorrecte ou ambiguë concernant la loi marocaine 54.23 ;
- une confusion encore présente entre validité de prescription et règles de remboursement ;
- un résumé de backlog conservant des valeurs marocaines non confirmées ;
- Peppol présenté comme un simple document imprimé ;
- le tarif INAMI 2026 non intégré alors qu'il était disponible ;
- des statuts fiscaux contradictoires ;
- une validation gate citée dans un document mais absente d'un autre ;
- des observations du dépôt présentées avec une confiance excessive alors que le code source n'était pas inclus dans l'archive documentaire.

## 2. Statut actuel

La Phase 0.5D a :

- réécrit le document principal ;
- consolidé le registre réglementaire ;
- resynchronisé le backlog et les validation gates ;
- intégré les sources officielles 2026 disponibles ;
- neutralisé les choix techniques prématurés ;
- distingué le `GO pour audit architectural` du `NO-GO pour commercialisation avant validation locale`.

## 3. Décision

Le présent rapport ne doit plus être utilisé comme source de décision autonome.
