# Registre réglementaire consolidé — MMV Belgique & Maroc

> **Version Phase 0.5D — 9 juin 2026.** Ce registre distingue les règles confirmées, conditionnelles et non confirmées. Il constitue une base documentaire pour l'audit architectural, **pas un avis juridique ni une certification de conformité commerciale**.

## États de fiabilité

- **CONFIRMED** : information directement établie par une source officielle actuelle.
- **CONDITIONAL** : information officielle, mais dont l'applicabilité dépend du profil, du rôle, de la transaction, de la date ou d'un texte d'exécution.
- **UNCONFIRMED_VALIDATION_REQUIRED** : information non établie par une source officielle suffisamment précise ; aucune valeur ne doit être codée par défaut.

## Catégories

1. obligation légale ; 2. exigence fiscale ; 3. remboursement/éligibilité ; 4. prescription ; 5. pratique professionnelle ; 6. exigence commerciale ; 7. choix produit ; 8. information non confirmée.

## Règles de prudence pour la Phase 1

1. Les éléments `CONFIRMED` peuvent orienter l'audit, mais leurs valeurs doivent rester versionnées et configurables lorsqu'elles évoluent dans le temps.
2. Les éléments `CONDITIONAL` doivent être modélisés comme variantes de contexte, jamais comme constantes globales.
3. Les éléments `UNCONFIRMED_VALIDATION_REQUIRED` ne doivent créer ni valeur par défaut, ni blocage métier, ni classe spécifique imposée.
4. La Phase 1 peut commencer : elle évalue l'aptitude de l'architecture à recevoir ces variantes. La commercialisation reste soumise aux gates du marché concerné.
